      About

      Flash Cards is a study app for organizing what you're learning into decks of flashcards. Group related questions together, flip a card to check the answer, and practice a deck one card at a time.

      Want to add your own deck? Paste a JSON array of cards into the New Deck form, matching this shape: 

      {
  "name": "Deck Name",
  "color": "#64d583",
  "cards": [
    {
      "question": "What does HTML stand for?",
      "answer": "HyperText Markup Language"
    }
  ]
}
